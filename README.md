## เกี่ยวกับ BultLy

BultLy เป็นแอปปรับแต่งเสียงบน Windows สำหรับเลือกอุปกรณ์เสียง ปรับการทำงานให้เหมาะกับเครื่อง และบันทึกโปรไฟล์ไว้ใช้ครั้งต่อไป

| ฟังก์ชัน | การใช้งาน |
| :--- | :--- |
| 🎚️ ปรับแต่งเสียง | ตั้งค่าเสียงตามรูปแบบการใช้งานของคุณ |
| 💾 โปรไฟล์ | บันทึกและเรียกใช้การตั้งค่า |
| ⚙️ โหมดประมวลผล | เลือกโหมดให้เหมาะกับเครื่องและความหน่วงที่ต้องการ |
| 🚀 เริ่มพร้อม Windows | เลือกให้แอปเปิดเมื่อลงชื่อเข้าใช้ Windows |
| 🔊 เริ่มเสียงอัตโนมัติ | ตั้งค่าแยกจากการเปิดแอปพร้อม Windows |

## ดาวน์โหลด

เปิดหน้า **Releases** ของ repository นี้ แล้วเลือกไฟล์ตัวติดตั้งในหัวข้อ **Assets** ของรุ่นที่ต้องการ

- **ไฟล์ `.exe`** — ดาวน์โหลดแล้วเปิดตัวติดตั้งได้เลย
- **ไฟล์ `.zip`** — แตกไฟล์ทั้งหมดก่อน แล้วเปิดตัวติดตั้ง `.exe` ที่อยู่ภายใน

เลือกไฟล์ชื่อ `BultLy-Setup…` ที่ผู้พัฒนาแนบไว้ ส่วน **Source code (zip / tar.gz)** ที่ GitHub สร้างให้ไม่ใช่ตัวติดตั้งแอป

> [!IMPORTANT]
> BultLy เป็นซอฟต์แวร์เชิงพาณิชย์ การดาวน์โหลดตัวติดตั้งไม่ได้ให้สิทธิ์ใช้งานแบบชำระเงินโดยอัตโนมัติ โปรดติดต่อผู้พัฒนาเพื่อซื้อสิทธิ์และสอบถามเงื่อนไขก่อนใช้งาน

## ความต้องการระบบ

| รายการ | รายละเอียด |
| :--- | :--- |
| ระบบปฏิบัติการ | Windows 10 หรือ Windows 11 แบบ 64 บิต |
| Visual C++ Runtime | Microsoft Visual C++ Redistributable **X64** รุ่นที่ตัวติดตั้งระบุหรือใหม่กว่า |
| ส่วนแสดงผล | Microsoft Edge WebView2 Runtime |
| อุปกรณ์เสียง | อุปกรณ์เสียงที่ Windows ตรวจพบและใช้งานได้ |
| VB-CABLE | ติดตั้งแยก หากการเชื่อมต่อเสียงที่คุณใช้งานต้องอาศัยสายเสียงเสมือน |

ดาวน์โหลดส่วนประกอบจากผู้พัฒนาโดยตรง:

- [Microsoft Visual C++ Redistributable — เลือก X64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
- [VB-CABLE โดย VB-Audio](https://vb-audio.com/Cable/)

ส่วนประกอบเหล่านี้มีเงื่อนไขการใช้งานของผู้พัฒนาแต่ละราย โปรดอ่านเงื่อนไขก่อนติดตั้ง

## วิธีติดตั้ง

1. ดาวน์โหลดตัวติดตั้งจากหน้า **Releases**
2. หากได้รับไฟล์ ZIP ให้คลิกขวา → **Extract All / แตกไฟล์ทั้งหมด**
3. ปิด BultLy ที่กำลังทำงานอยู่ รวมถึงที่ซ่อนอยู่บริเวณไอคอนข้างนาฬิกา
4. เปิดไฟล์ `BultLy-Setup…exe`
5. อ่านข้อตกลงและติ๊กยอมรับหากตกลงตามเงื่อนไข
6. ตรวจส่วนประกอบที่จำเป็น และเลือกว่าจะสร้างทางลัดบน Desktop หรือไม่
7. ติดตั้งให้เสร็จ แล้วเปิด **BultLy** จาก Start Menu หรือทางลัด

ตัวติดตั้งลงโปรแกรมสำหรับบัญชี Windows ปัจจุบัน โดยใช้ตำแหน่ง:

```text
%LOCALAPPDATA%\Programs\BultLy
```

ผู้ใช้ตัวติดตั้งสำเร็จรูปไม่ต้องติดตั้ง Python, VS Code หรือ NSIS

## เริ่มใช้งาน

1. เลือกอุปกรณ์เสียงที่จะใช้งานในแอป
2. ปรับการตั้งค่าและเลือกโหมดประมวลผลที่เหมาะกับเครื่อง
3. เริ่มการทำงานของเสียงและตรวจสอบผลลัพธ์
4. บันทึกเป็นโปรไฟล์เมื่อตั้งค่าได้ตามต้องการ

หากเสียงขาดหรือกระตุก ให้ลองเลือกโหมดที่ใช้บัฟเฟอร์มากขึ้น แล้วทดสอบอีกครั้ง ความหน่วงและความเสถียรขึ้นอยู่กับอุปกรณ์ ไดรเวอร์ และภาระงานของเครื่องด้วย

## ตั้งค่าเริ่มอัตโนมัติ

เข้าแอปแล้วไปที่ส่วน **ประสิทธิภาพ**

| ตัวเลือก | ทำหน้าที่ |
| :--- | :--- |
| **เปิดแอปเมื่อเข้า Windows** | เปิด BultLy อัตโนมัติหลังลงชื่อเข้าใช้ Windows |
| **เริ่มเสียงเมื่อเปิดแอป** | เริ่มการทำงานของเสียงเมื่อเปิด BultLy |

สองตัวเลือกนี้ตั้งค่าแยกกันได้

<details>
<summary><strong>เคยกด “ไม่เปิดอัตโนมัติ” แล้วเปลี่ยนใจ ต้องทำอย่างไร?</strong></summary>

เปิด BultLy → **ประสิทธิภาพ** → ติ๊ก **เปิดแอปเมื่อเข้า Windows**

แอปจะจำคำตอบเดิม จึงไม่ถามซ้ำทุกครั้งที่เปิด แต่เปลี่ยนการตั้งค่าจากช่องนี้ได้เสมอ

เมื่อปฏิเสธ แอปจะไม่ลงทะเบียนให้เริ่มพร้อม Windows จึงอาจไม่มีรายการ BultLy ใน Task Manager → Startup apps ให้กด Enable ต้องเปิดตัวเลือกในแอปก่อน แล้วปิดและเปิด Task Manager ใหม่เพื่อตรวจสอบรายการ

</details>

## อัปเดตและถอนการติดตั้ง

**อัปเดต:** ปิด BultLy ดาวน์โหลด Setup รุ่นใหม่จาก Releases แล้วติดตั้งทับตำแหน่งเดิม โปรไฟล์และการตั้งค่าผู้ใช้เก็บแยกจากโฟลเดอร์ติดตั้ง

**ถอนการติดตั้ง:** เปิด **Settings → Apps → BultLy → Uninstall** หรือใช้รายการถอนการติดตั้งใน Start Menu → BultLy

ตัวถอนการติดตั้งจะลบไฟล์โปรแกรมและทางลัด โดยเก็บโปรไฟล์และการตั้งค่าของผู้ใช้ไว้

## สิทธิ์การใช้งาน

BultLy ใช้เงื่อนไขการใช้งานเชิงพาณิชย์ตาม **APP_LICENSE.txt** ที่แนบมากับโปรแกรม

- ผู้ซื้อหนึ่งคนสามารถติดตั้งและใช้งานบนเครื่องของตนเองได้หลายเครื่อง ตามข้อตกลงฉบับเต็ม
- ห้ามจำหน่ายต่อหรือแบ่งปันสิทธิ์การใช้งานส่วนของ BultLy ให้บุคคลอื่น
- ข้อจำกัดของ BultLy ไม่กระทบสิทธิ์ที่ใบอนุญาตซอฟต์แวร์บุคคลที่สามหรือกฎหมายให้ไว้

โปรแกรมใช้ส่วนประกอบของบุคคลที่สาม ซึ่งยังอยู่ภายใต้ใบอนุญาตของแต่ละราย รวมถึงฟอนต์ **Noto Sans Thai** ภายใต้ **SIL Open Font License 1.1**

อ่านเอกสารฉบับเต็มได้จากเมนู **ข้อมูลและใบอนุญาต** ในแอป หรือจากโฟลเดอร์ที่ติดตั้ง:

| เอกสาร | เนื้อหา |
| :--- | :--- |
| `APP_LICENSE.txt` | ข้อตกลงการใช้งาน BultLy |
| `LEGAL_NOTICES.txt` | ประกาศและข้อมูลส่วนประกอบบุคคลที่สาม |
| `legal/` | ใบอนุญาตและประกาศลิขสิทธิ์ฉบับเต็ม |
| `legal/installer/NSIS_NOTICES.txt` | เอกสารสิทธิ์ส่วนตัวติดตั้ง |

ข้อความในหน้านี้เป็นข้อมูลสรุป โปรดอ่านข้อตกลงฉบับเต็มก่อนยอมรับและติดตั้ง
