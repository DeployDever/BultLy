legal/snapshot contains original notices and metadata from the supplied
environment. legal/upstream contains supplemental, unmodified upstream
documents. legal/PROVENANCE.json records their sources
and hashes. Upstream reference documents are not a blanket grant for every
native binary or later version.

The Windows build embeds legal/current-build using licenses from the actual
installed package versions and Python runtime. BUILD_INVENTORY.json records
collected data/binaries and package versions. FILE_HASHES.json records the
distributed files; neither file is a legal certification.

OpenSSL 3.0.21 — Apache License 2.0. The versioned license is included at

legal/current-build/PACKAGE_INVENTORY.json is generated from the selected
Python modules as well as binaries/data. Any collected setuptools, packaging
or other additional distribution has its installed license files copied,
including vendored notices present in that distribution. Supplemental BSD
notices for proxy_tools are explicitly recorded instead of silently ignored.

legal/current-build/NATIVE_REVIEW.json distinguishes binary references with
matching hashes from native binaries still requiring provenance review.
A successful build does not resolve those outstanding entries automatically.
APP_LICENSE.txt contains the publisher's application terms. It does not replace
third-party licenses or independently establish redistribution rights.
